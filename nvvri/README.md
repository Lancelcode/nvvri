# Nvvrii!

A nursery finder proof of concept — search, compare, and enquire at nurseries near you.

Built with Next.js 15, TypeScript, and React 19 as a personal project to explore the childcare discovery problem.

## Stack

- **Next.js 15** — App Router, Server Components
- **TypeScript** — end-to-end type safety
- **React 19** — client-side interactivity

## Features

- Full-text search by nursery name, area, or postcode
- Filter by max daily price, child age group, and space availability
- Nursery cards with ratings, Ofsted status, fees, and hours
- Two-step enquiry flow with form state management
- Responsive grid layout

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
